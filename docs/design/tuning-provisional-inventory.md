**미해소 ★1순위 2건(결함성 — 폴리시 수정 대상):**

- `tool_tier.gd:HOE_AOE / CAN_AOE = [1×1, 1×1, 1×3, 1×3, 3×3]` — **명동 괭이·물뿌리개 2,000냥의 실효 이득 0.** 코드 주석에도 "★owner 큐 1순위 재검토"라 박제됨. `[1×1, 1×3, 1×3, 3×3, 3×3]`이면 해소(상수 1줄).
- `daily_luck.gd:W_SALVAGE=0.5` + main 인양 훅 — **대흉(운 −0.10) 날 인양 퍼밀 `30+(−50)<0` → 0‰**로 인양 완전 정지. 하한 클램프 미도입. `daily_luck.gd:FLOOR_MITIGATED`는 삽사리 만점 전용이라 이 구멍을 안 덮는다.
