> **상태:** 승인 (2026-08-13 self-grill — Fable 5 캠페인 §2-1 자문자답 변형).
> **이행:** [ADR-0067](./0067-slice9-narrative-books-kickoff.md) 결정 1이 신설 예약한 후속 슬라이스 「S9b 조연·척추」의 착수 확정이다. 서사 바이블 §5.2~5.4(조연 로스터)·§6.1(해결 게이트)·§6.2(그날 밤 고백 전원 필수)·§6.5(연출 등급제·B5 클라이맥스 시퀀스)·§8.2(S9b 서랍)를 **빌드 가능한 결정으로 변환**한다.

## 맥락

S9(S9층)가 서사 인프라 4종(선택지·컷신 러너·편지·훅 일습)과 메인 3인 아크(B1~B3 세 조각), Books, T1 2인(모찌·네오)을 닫았다. 척추 해결 게이트 `AND(세 조각 ♡4) + 공허 비트(B4) + 조연 11인 전원 ♡3`(bible §6.1)에서 **첫 항만 채워진 상태**다.

리서치가 밝힌 것 셋. ㉠ **게임에 엔딩이 없다** — B4~B7이 미착수라 메인 서사가 "조각 성립"에서 멈추고, `_end_run`은 호출부 0의 사장 코드다(main.gd:16308). 캠페인 최상위 우선순위 "끝까지 플레이되는 것"의 유일한 격차가 이것이다. ㉡ **조연 9인은 코드에 전무하다** — 현 주민 11인(메인 4+네오·모찌+점주 5)은 바이블 T1 로스터와 다른 집합이고, 깨비·켄·미르·루카·강림·설화·스칼렛·세레나·프로스티는 레코드조차 없다. "훅만 붙이면 개통"(§8.2)은 서사 층 한정이고 인물 층은 풀 온보딩이다. 다만 T7 프레임워크(1인 추가=파일 1+레코드 1·main.tscn 무수정)와 나루 주민집 11채(모찌=집 4·강변 2채=세레나 예약)가 깔려 있어 인물당 비용은 실측 최저점이다. ㉢ **Slice 10은 S9b 없이 100%로 닫히지 않는다** — ROADMAP Slice 10의 절반(엔드게임 롱테일)이 "척추 엔딩(해방) *이후* 옵션"으로 명문화돼 있는데 그 척추가 ADR-0067 절단으로 S9b에 있다.

## 결정

### 1. 착수 순서 = S9b가 Slice 10에 선행한다

근거 넷. ①우선순위 불변("끝까지 플레이되는 것 > 기능이 많은 것") — S9b가 엔딩을 만들고 Slice 10은 기능을 더한다. ②Slice 10의 엔드게임 절반이 해방 엔딩(B6~B7)에 의존(ROADMAP 명문) — 먼저 가면 "한 시스템 100%" 원칙을 구조적으로 위반한다. ③역의존은 도달 수치 튜닝뿐인데 그것은 §8.2·본 ADR 결정 12가 폴리시 루프로 이월한다. ④훅·병렬 프로토콜·워크트리(`s9-narrative`) 관성이 살아 있어 지금이 인물당 개통 비용 최저점이다. **ROADMAP Slice 10 의존 표기 "척추(S9)"는 절단 이전 stale — "척추(S9b)"로 정정한다(동반 갱신).** Slice 10은 S9b 종결 후 착수하며, 그 시점에 의존이 전부 실충족된다.

### 2. 스코프 = ADR-0067 예약 4축 + 조연 연애·결혼 개통

①조연 9인 점진(전원 ♡3 재료 완성) ②척추 B4~B7(B5 재구성 미니 씬+S등급 이음매) ③엔딩 에필로그(`_end_run` HeartBar 전환 포함) ④옥자 트랙(ADR-0067 결정 10-ⓓ 공백 확정 포함). 추가로 **조연 연애·결혼을 T1 11인 전원 개통한다**(bible §6.2 ♡4 생전 죄 고백·♡5 연애·결혼 후 반전 로맨스가 조연 아크의 확정 구조 — S9에서 "깊은 단골"로 닫은 모찌·네오도 소급 개통). S9 이월 재평가 항목(선택지 위젯 승격·컷신 순차 전용/대기 동사/대화 삽입·이혼 대화창 승격·편지 재열람 UI)은 **콘텐츠가 실제로 부딪히는 시점에만** 소화하고 선제 재설계하지 않는다.

**스코프 밖:** 도달 수치 튜닝(결정 12)·컷신 구역 인지 훅의 전면 도입(결정 5의 우회 규약 유지·부딪히면 그때 최소 확장)·장기 동기 이중화(해방 척추의 제2 동기 기능을 S9b *관찰* 후 판단 — ADR-0067 잠정 유지).

### 3. 조연 1인 = 풀 온보딩 묶음 (인물 층 + 서사 층 한 태스크)

1인 = 레코드+캐릭터 파일(T7 프레임워크)+집 배정(나루 주민집 — 세레나=강변 예약 준수)+스테이션/스케줄(바이블 "나라카 연결" 결에서 파생)+affinity(서브=쉼터 2채널·활동 채널 없음, §6.1)+gift_prefs 오버라이드+`Resident.BIRTHDAYS` 추가(달력 마커 자동)+시트/초상 아트+서사 묶음(일상 4단·♡1~4 관문 발화/컷신·♡3 그날 밤 고백·♡4 생전 죄 고백·절기 물음 4·생일·고백/작별 본문·여진 편지). 로스터 파급 회귀 트리오(resident·frame·home_deco)와 관계 탭 스크롤(S8-T1 기구현)이 받친다.

### 4. 점진 순서(잠정) — 세레나 마지막·강림 후반 고정, 2인 병렬 허용

**깨비 → 켄 → 설화 → 스칼렛 → 미르 → 루카 → 프로스티 → 강림 → 세레나.** 확정 근거: 세레나=최고비용·마지막(bible §5.3 명문)·강림=봉인 법칙 최고 수위라 금칙어 가드·고백 문법이 조연 7인으로 성숙한 뒤(§5.2 3단 경계). 잠정 근거: 앞 6인은 그날 밤 인과 군집 순(약방 조력 켄·설화 / 도박장 축 스칼렛·미르 / 증폭자 깨비 / 뿌리 루카)이되 구현 단순한 깨비부터, 프로스티=B4 공허 직결이라 척추 직전 배치. 구현은 **2인 병렬**(S9 병렬 프로토콜 — isolation:worktree 구현 병렬·테스트 순차 창·cherry-pick 결합)을 기본으로 하되 강림·세레나는 단독 태스크.

### 5. 조연 볼륨 상한(잠정) — 메인의 절반 결

1인당: 대사 100~150줄 · 관문 컷신 ♡1~4 각 1(연출 등급 2 · **♡3 그날 밤 고백=필수 세트피스**) · 절기 물음 4 · 여진 편지 2~3통 · 생일 1 · confession/divorce 본문 · **spouse_lines 4축**(메인 8축의 절반 — day%4·반전 로맨스 페이오프의 최소 성립). 컷신 NPC 이동=암전 뒤 규약 유지(T1 2인의 "npc 동사 0" 회피는 관문 컷신 4개 체제에선 비현실적 — 암전 은폐로 완화). 볼륨은 상한이지 목표치가 아니다(S9-T4 판단 승계).

### 6. 봉인 법칙 확장 — 소프트 게이트 ㉠ 기계화 + 조연 금칙어 + 강림 전용 세트

- **소프트 게이트 ㉠(♡3 고백은 대화재 접촉 후):** 기계 판정 = **메인 3인 중 1인 이상 stage≥3**. 온보딩은 대화재를 언급하지 않음을 코드로 확인했으므로(B0=통보+범용 복선뿐) 대변 불가 — 메인 ♡3 씨앗 컷신이 첫 대화재 접촉이다. 미충족 시 조연 ♡3 관문은 대기(기존 `pending_promotion` 문법 그대로·점수 손실 없음). 모찌·네오의 기존 ♡3 비밀 비트에도 소급 적용한다.
- **조연 금칙어:** ♡3 고백=자기 파편+죄책감만(중심 진실 4금지 — 옥자 희생/기억 봉인/마녀=연인/플레이어 죄목), ♡4=자기 생전 죄까지만. 기존 31어 가드를 조연 파일 각각의 arc_test에 상속.
- **강림 전용 세트(§5.2 3단 경계):** 🟢 파편("율법을 어긴 계약을 했다")까지 허용 · 🔴 사실 진술 4종 영구 금지 — 강림 파일 전용 금칙어 회귀 가드 별도. 🟡 확증선("끄덕임만")은 B5 시퀀스가 소유(결정 8).

### 7. B4 공허 비트 = 별도 비트 · `_spine_bits` 원장 신설

B4는 프로스티 ♡3 관문(공허 그 자체의 비밀)이 **겸임하지 않는다**(§6.5 "B4 떡밥 ≠ B5 회수" 경계의 앞 단도 동일 원리 — 조연 아크와 척추 비트의 소유 분리). 트리거(잠정)=**프로스티 ♡3 관문 완료 후 첫 취침 다음 아침**, 자동 컷신(등급 2·플레이어 단독·공허 이펙트·집 앞). 세레나 레시피의 "일반 생전 기억 자극"은 세레나 아크 내 떡밥 대사로만(비트 아님·옥자 봉인 무접촉 §5.3). 원장=`_spine_bits`(B4~B7 비트마스크·main 소유·세이브 가법 키 1 — `_heart_bits` 규약 동형).

### 8. B5 재구성 = 미니 씬 상태 머신 + `spine.gd` 게이트 판정

- **게이트 판정 = `spine.gd` 신설**(순수 static·deed.gd 결) — `AND(미호·멜·바나 stage≥4) + B4 비트 + T1 11인 전원 ♡3 고백 비트`. 로스터 고정 안전장치 ㉑ 준수: 요구 명단은 바이블 T1 11인 상수로 박제(점주 5인·추후 조연은 요구 밖).
- **발동:** 게이트 충족 후 **미혹 심층 옥자 집 진입**(§6.5 1 — 지리-서사 정합. 현 옥자 집=잠긴 외관이므로 게이트 충족 시 진입 개방이 곧 척추 발동).
- **재구성 퍼즐:** FishingSession 규범 4번째 순수 상태 머신 — 파편 15개(세 조각+11 증거+공허)를 잇는 최소 능동 메카닉(§6.5 3 "봉인의 법칙 메카닉화" — 자동 몽타주 기각 확정 준수). 그레이박스=한지 UI 점·선(방향키/마우스)·**무실패**(§6.5 4 강림 안전장치=일정 무입력 시 강림 파편이 다음 연결을 나직이 지시 — 🟡 "끄덕임만"의 정확한 구현 자리). 난도·연출 디테일은 그레이박스 후 아트 패스 각론.

### 9. S등급 = 러너 `illust` 동사 1개 확장 · 원화는 owner-Gemini 큐 전용

B6 귀환·B7 해방 전용으로 컷신 러너에 다섯 번째 동사 `illust`(풀스크린 일러스트+텍스트)를 개방한다 — **ADR-0067 결정 2 "다섯 번째 동사=ADR 개정 요구"의 그 개정이 본 결정이다**(4동사 정규화·미지 동사 거절 규약은 그대로 상속). 인스타툰체 원화는 PixelLab 불가 영역(도트 툴·비인간 초상 한계 3회 실증: 무골·옹이·주방요괴)이므로 **아트=owner-Gemini 스펙카드 큐 전용**으로 보내고, placeholder=먹 암전+세로 대형 텍스트(한지 결)로 게임을 상시 완성 상태로 유지한다(캠페인 §2-2). 에셋 훅=`assets/cutscene/<id>.png` 드롭인(코드 0줄 교체).

### 10. 옥자 트랙 = deed 단독 채널 · 이혼 경력 무관(10-ⓓ 확정)

- B6 후 옥자 affinity 개통(`needs_affinity` 활성)하되 **선물·대화·활동 3채널 전부 차단, deed 채널 단독**(§6.1 "일반 하트 그라인드 아님" — CONTEXT 정합). deed 3반전의 원장은 전부 기존재: 망각 반전=Books 기증 수(museum 원장)·외면 반전=B4~B5 비트(`_spine_bits`)·부재 반전=누적 수확(`run_harvested`).
- **10-ⓓ 확정: 이혼 *경력*은 옥자 트랙 진입을 막지 않는다**(ADR-0022 재구애 허용의 결). 단 **현재 배우자가 있으면 잠금** — ADR-0032 "미혼 완주자 엔드게임"의 기계 해석은 *현재 상태*이지 이력이 아니다. 이혼(50,000냥)이 기존 억지력.
- 옥자 결혼=강림 주례 연출(§6.3 — 정표 특별판·구체 연출은 B7 태스크 각론). §6.4 결혼 경로별 톤(씁쓸한 축복 포함)은 B6~B7 본문이 이행.

### 11. 엔딩 = B7 후 1회성 에필로그 · RUN_DAYS 게이트 부활 없음

B7 해방 컷신 직후 **1회성 에필로그 화면**(사장 `_end_run` 정산 화면을 재목적화 — 경과일·자산·관계 요약)을 띄우고, 닫으면 **코지 샌드박스로 복귀**(게임 종료 아님 — §6.4 "머무름은 선택"·스타듀 평가 결). 이때 `affinity.heart_bar()` ♥ 문자열을 HeartBar 스프라이트로 전환(S8-T10 이월 소화 — neodgm ♥ 글리프 부재 두부의 마지막 잔재).

### 12. 검증 계약 + 수치 튜닝 이월
