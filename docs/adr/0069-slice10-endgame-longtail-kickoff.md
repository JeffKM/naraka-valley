## 맥락

S9b가 **게임에 엔딩을 세웠다**(척추 B0~B7 · 1회성 에필로그 → 코지 샌드박스 복귀). 그 결과 `_spine_bit_seen(SPINE_B7)` **한 줄**로 "해방 후"를 판정할 수 있게 됐고, 해방 후 세계가 코드 층에서 처음으로 주소를 가졌다.

리서치가 밝힌 것 둘.

㉠ **해방 후 샌드박스에 목표 층이 없다.** 코드 실측으로 만렙(5스킬 lv10 + 도구 4티어) 이후 남는 성장 축은 **옥자 트랙과 혼백관 기증 11종뿐**이다. 스타듀에서 이 자리를 Mastery·Qi 챌린지·황금 호두·완벽함이 채우는데 나라카는 그 넷 전부가 서랍 또는 기각 상태였다. 엔딩을 봤는데 다음 날 아침에 할 일이 어제와 같다 — 이 공백이 Slice 10이 메우는 것이다.

㉡ **곁들이 목록의 절반은 이미 흡수됐다.** ROADMAP이 나열한 11항 중 **게잡이통(S3)·이끼(S4)·게시판(S2)·우편 서사 채널(S9)·저승 TV/예보(S7 점괘 거울)**는 해당 루프 슬라이스가 기흡수라 재론 대상이 아니다. 남은 것은 **팬닝·결정기·스프링클러 상위 티어·레어크로우 8종 완성·여행 상인·탈것·펫**이고, 이들 각각이 선행 슬라이스에 **예약된 이음매**(RANGE 오프셋·`DELUXE_RADIUS` 상수·LETTERS 테이블·목공방 건축 서비스 원장)를 이미 갖고 있어 실장 비용이 최저점이다.

따라서 Slice 10 = **곁들이 마감(㉡의 잔여 7건) + 해방 후 목표 층 신설(㉠의 공백)** 두 묶음이다.

## 결정

### 1. 스코프 3분류 확정 — 채택 / 서랍 재확인 / 기각

**채택 =** 결정 2~12의 로스터(팬닝·결정기 / 스프링클러 상위 2티어·우편 첨부 / 레어크로우 8종 완성 / 저승 보부상 / 탈것·펫·동행 혼 / 카페 3단·늘봄방·화분 / 명부 도감 / 반딧넋 / 명부 시련장·경지).

**서랍 재확인**(이번 슬라이스에서 안 연다 — 사유를 각각 기록한다):

- **멜 카지노·아케이드** — 설계 grill 자체가 미개방이다. [ADR-0021] 멜 보너스와 [명부의 운]의 결합(도박 확률에 운 계수를 어떻게 태울지)이 별도 grill 사안이라 곁들이로 끼워 넣을 크기가 아니다.
- **혼연못(어항)** — 게잡이통과 공급 역할이 중복되고, "양식만이 낼 수 있는 고유 산출"의 논거가 아직 없다. 논거가 서면 그때 연다.
- **무기 서랍류·트링켓** — [ADR-0063] 결정 11 유지. 트링켓은 바나 사역마(박쥐·검은고양이)와의 위상 정리가 선행이다.
- **지하실 / 캐스크 숙성** — 아티산 숙성 축 자체가 [ADR-0064] 서랍이다.
- **시드 메이커** — `craft_catalog`의 희귀 씨앗 제작이 이미 그 자리를 선점했다.
- **버섯 통나무** — 이끼·수액 채취기가 "나무 위 패시브 산출" 자리를 소유한다.

**기각**(안 한다 — 근거를 남긴다):

- **① 집 업그레이드 *주방 단계*.** [ADR-0062]가 서랍으로 미뤄 둔 사유가 실측으로 소멸했다: *방 확장*은 S8 안방 확장([ADR-0066])이 이미 이행했고, *요리 소비처*는 [ADR-0064]가 카페로 확정했다. 주방을 집에 넣으면 카페 도메인을 침식한다.
- **② 완벽함 100% 합산 지표.** 기존 기각을 유지한다. 결정 9의 [명부 도감]은 진척을 *나열*만 하며, **합산 퍼센트·진엔딩 연출은 상속하지 않는다**.

**폴리시 이월 재확인:** 도달 수치 튜닝은 여전히 폴리시 루프 몫이다([ADR-0068] Consequences 자구 — "Slice 10 곁들이가 경제를 마저 얹은 뒤가 정확한 시점"). 즉 이 슬라이스는 튜닝의 *대상*을 완성하는 슬라이스이지 튜닝을 수행하는 슬라이스가 아니다.

### 2. 팬닝(사금) + 결정기

- **팬닝** — 물가 사금 스폿을 **삼도천·황천해 한정**으로 둔다(카탈로그 §1-E "낚시터 부수 채취로 흡수" 자구의 이행). 스폰은 **day-해시 결정적**(구역당 0~2 · 전역 `randf` 금지 — 날씨·운의 day 파생 규약 동형). 채취는 **도구 불요 [F]**·[혼력] 소량(잠정 4). 산출 = 광석·냥·저확률 보석 + **결정기 부품**(잠정 3부품을 모으면 제작).
- **결정기** — 설치 기계다: 보석 1종을 넣으면 일정 기간 후 같은 보석을 복제하고, 회수하면 반복한다. 광물별 시간 차등(잠정: 하위 보석 2일 ~ 명옥 5일). ⚠️ **오색혼옥은 복제 불가**([ADR-0063] 초희귀 지위 보존 — 스타듀가 프리즘 조각을 결정기에서 배제한 것의 상속).
- **경제 가드:** 복제 시간이 채광 시세를 깨지 않아야 한다. 구체 값은 폴리시 튜닝 대상으로 **명시 이월**한다(결정 1 참조).

### 3. 스프링클러 상위 2티어 + 우편 아이템 첨부

- **스프링클러** — `sprinkler.gd`의 예약 경로를 그대로 쓴다: 티어별로 바뀌는 것은 **RANGE 오프셋 하나뿐**이고 급수 로직·배치·세이브는 불변이다. 2티어 = 3×3(잠정명 **「넋비 스프링클러」**·유철 주괴 게이트), 3티어 = 5×5(잠정명 **「단비 스프링클러」**·황천금 주괴 게이트). 제작은 농사 스킬 해금(수치 잠정).
- **우편 첨부** — `mailbox.gd`의 `LETTERS`에 **첨부 필드(items/gold)** 를 신설하고 수령을 배선한다. ⚠️ **단 메뉴 해금 경로 비사용 규약은 불변이다**(`mailbox.gd:7` 주석 · [ADR-0064] 발견 게이트) — 첨부는 **물건·냥 전달만** 하며 레시피/콘텐츠 해금 창구가 되지 않는다.

### 4. 레어크로우 8종 완성

[ADR-0051] 결정 5가 예약한 "8종 스킨 → 완성 시 디럭스"를 닫는다. 6종 아이템 추가(**기능·반경 동일한 순수 스킨** — 결정 5 자구)+밭 배치 코드+8종 완성 판정 → `DELUXE_RADIUS=16` 배선(`crows.gd:18` 예약의 이행)+혼백관 추적 전시.

**획득처 8슬롯 재분배**([ADR-0064] 결정 12 카페 이벤트 데이 서랍을 대체 — 서랍에 걸린 슬롯을 살아 있는 창구로 옮긴다):

① 혼백관 마일스톤(기존) ② 야시장(기존) ③ 만물상 ④ 전령(우편 첨부 — **결정 3 의존**) ⑤ 저승 보부상(결정 5에서 등재) ⑥ 낚시 더비 보상 ⑦ 장원제 보상 ⑧ 명부 시련장 상점(결정 11에서 등재).

owner의 "획득처를 전부 구현한 뒤에만 배치한다" 원칙은 **슬라이스 내 태스크 순서**로 충족한다(T2가 ①~④·⑥·⑦, T3이 ⑤, T8이 ⑧).

### 5. 저승 보부상(여행 상인)

- 잠정명 **「보부상」**. 출현 = **7의 배수 날**(7·14·21·28 — 주 1회·잠정), 장소 = 나루 다리 남단(잠정).
- 재고 = **day-해시 결정적 10슬롯 + 가구 1 + 희귀 1**(가격 변동 ±잠정).
- **[ADR-0034] "여행 상인 흡수" 자구의 이행처**다 — Books 미보유분의 **저확률 입수처**를 여기서 연다. 아울러 [집 꾸미기] 테마 세트 가구의 입수처를 겸한다.
- **야시장(성야 15 절기 행사)과 역할 분리를 명문화한다:** 야시장 = *절기 이벤트 한정판*(달력 고정·1년 1회), 보부상 = *상시 리듬의 랜덤 재고*(주 1회·매번 다름). 같은 "임시 상인 오버레이" 아키타입이지만 리듬과 재고 성격이 갈리므로 중복이 아니다.

### 6. 탈것

- **마구간 = [목공방] 건축 서비스의 3번째 항목**([ADR-0062] 결정 7 원장의 확장 — 새 건축 시스템을 만들지 않는다). 비용 잠정 10,000냥 + 원목 100 + 유철 주괴 5 · 공사 2일.
- 저승 말 1종(잠정명 **「먹갈기」** — 먹빛 갈기).
- 승마 = **야외 한정** 이동 ×1.5(잠정) · 실내/컷신 불가 · 소환 = 휘파람(마구간 완공 시 증정).
- **그레이박스 = 속도 버프 + 추종 스프라이트**, 승마 합성 시트는 아트 패스(T9)로 넘긴다.

### 7. 코지 펫

- 잠정 = 삽살개 강아지 **「삽사리」**(귀신 쫓는 개 — 저승 결에 정합). ⚠️ **[바나] 사역마(박쥐·검은고양이)와 위상 분리를 명문화한다**: 사역마 = 바나의 전투/도메인 동반자, 펫 = 순수 코지 존재(전투 관여 0).
- 획득 = 마을 이벤트 1회(잠정). 상호작용 = 쓰다듬 1/일 + 물그릇. **우정 축 신설**(수치 잠정).
- **만점 보상 = [명부의 운] 하한 +1눈금(대흉 완화).** 카탈로그의 "소소 행운" 결정을 S7 운 시스템과 결합해 **중복을 정리한 것**이다 — 운을 평균적으로 올리는 게 아니라 *바닥을 덜 아프게* 하는 방향이라 [ADR-0019] +% 금지와 충돌하지 않는다.

### 8. 카페 마일스톤 3단 = 궁극 명소 + 늘봄방(온실) + 화분 최소형

- **3단 = 사다리의 *최종* 단계 「저승의 명소」.** `cafe_milestone.gd` STAGE_2의 "3단 서랍" 주석을 이행하며, **단수를 3으로 확정**한다(무한 사다리가 아니다).
- **축 = [ADR-0029] "옥자=정점" 이행** — 옥자에게 별도 미터를 두지 않고 **누적 서빙 매출**이 대변한다([ADR-0064] 결정 7 문법 상속 · 문턱 잠정).
- **보상 = 늘봄방 건축 프로젝트 해금**([농장 건물 로스터]의 기정 명명 — 목공방 건축 · 비용 잠정) + 명소 연출. 온실을 카페 일구기 트리 상단의 보상으로 붙이는 것은 카탈로그 §1-B 온실 행의 "카페 일구기(ADR-0009) 롱테일 보상 후보" 자구를 그대로 확정한 것이다.
- **늘봄방 내부 = 절기 무시 경작면**(크기 잠정 10×8 · 스프링클러 호환 · 까마귀/잡초 무해). ⚠️ Track B가 늘봄방을 연기했던 사유는 "절기 사멸이 미구현이라 절기 우회의 가치가 성립하지 않는다"였는데, S7이 사멸을 실장해 **그 사유가 소멸**했다.
- **화분 = 실내 1×1 컨테이너 최소형.** 카탈로그 §2-6 "화분 #2 defer" 의 해제 조건이 "온실 슬라이스 시점"이었고 그 시점이 도래했다. **온실과의 차별 자구를 그대로 이행한다**: 절기 무시 · **매일 손 물주기** · **스프링클러 불가** · **[혼의 나무] 불가**.

### 9. 명부 도감

- **혼백관에 열람대 1기를 신설**한다. 기증대가 아니라 **자동 기록**이다(Books 트래커의 "분모 11" UI 선례를 따른다).
- **등재 기준 = 멜 출하대 출하 1회 이상.** [ADR-0021]이 환전을 출하대 단일 창구로 못 박았으므로, 스타듀의 "출하만 집계(선물·요리 재료는 미집계)"라는 비대칭이 나라카에선 **설명 없이 자연 성립**한다.
- 카테고리 = 작물 · 어종([물고기 도감] 서랍 흡수) · 채집물 · 광물 · 요리(융합 메뉴).
- 완주 보상 = **가벼운 트로피**(잠정 · 연출만). ⚠️ 합산 퍼센트·진엔딩 없음(결정 1 기각 ② 유지).

### 10. 반딧넋 숨은 수집

- 잠정 **45개**. 길 잃은 작은 넋이 **반딧불 형상**으로 세계에 숨어 있다(속죄·인도 테마에 정합 — 줍는 행위가 곧 인도다).
- 분포 = **전 구역 고정 배치 + 전 활동 저확률 드랍 혼합**(결정적 — 실제 표는 태스크에서 잠근다).
- 수집 = 혼백관 안치.
- **30개 = 명부 시련장 개방 게이트**(스타듀 "황금 호두 100 = Qi방" 문법 상속 — 게이트이면서 동시에 수집물이다). 잔여 15는 안치 마일스톤 보상(잠정).
- **명명 근거:** [혼불](여우불·혼불씨·혼불 바람)과의 어휘 충돌을 피하려고 "반딧"을 앞세웠다 — 불이 아니라 *넋*이 주어다.

### 11. 명부 시련장 + 경지

- **시련장** = 나락 심층의 챌린지 보드(무대 = 나락 진입로 곁 방 1 · 잠정). **주간 시련 1건 = `quest_board.gd` 중기 의뢰 프레임 재사용**(주 시드 문법 상속 — 새 퀘스트 엔진 0). 보상 화폐 **「시련패」** → 전용 상점. ⚠️ **품목은 레어크로우 ⑧·장식·편의 한정** — **재점령 정지류는 금지**한다([ADR-0055] 차등 재점령이 정체성이라 그걸 돈으로 끄는 상품은 시스템을 부정한다).
- **경지** = 5스킬 만렙 후 개방(스타듀 Mastery 상속). **무대 없는 UI 층**이다 — 스킬 패널의 확장이지 새 장소가 아니다. 포인트 = 만렙 초과 XP 적립(누적 문턱 잠정 5단), 보상 = 스킬당 유물 1점.
- **문법 가드:** 유물은 **flat 일회성·편의만**이며 **영구 % 곱셈 금지**([ADR-0019] — [저승 실용서]에 건 규칙과 동일한 가드) · **트링켓 슬롯 비상속**(결정 1의 서랍과 정합 — 장비 슬롯을 여는 순간 전투 grill 사안이 된다). 로스터는 태스크에서 잠근다.

### 12. 동행 혼 최소 구현

[ADR-0032] 결정 4의 이행이다. **혼례 후 잠정 14일 아침 탄생 이벤트**(1회성 컷신) · 최대 1(2호는 서랍) · 집 상주 · 상호작용 1종(인사/쓰다듬) · **이혼 시 잔류**(불가역 — [ADR-0022] 자녀 잔류 자구 그대로).

**옥자 혼인 포함 여부 = 잠정 포함.** 척추 B7 *이후*의 층이므로 서사 충돌이 없다 — 봉인 법칙이 관장하는 층이 아니다.

연출·스프라이트는 아트 패스 1종으로 잡는다.
