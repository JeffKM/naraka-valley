- 상태: 채택 (2026-08-11, Fable 5 캠페인 self-grill — 캠페인 §2-1 자문자답·owner 큐 적재)

## 맥락

Slice 1~6으로 전 활동 루프가 개통됐고, 절기는 `clock.gd`의 읽기 전용 파생(ADR-0045)으로 5개 시스템(과수·어종·채집·덤불·메뉴)이 이미 소비 중이다. 그러나 **전환 이벤트가 없고**(유일 감지 = `forage_spawn.gd:203` 로컬 판정), **날씨는 코드 0줄**(예약 스텁 3곳 — `_weather_calm()`·어종 `"weather": []`·HUD 자리), **축제는 2주 주기 카페 버프**(`festival.gd` CYCLE=14 — 파일 스스로 "캘린더가 생기면 이 한 곳만 교체" 명시)다. 설계는 CONTEXT·카탈로그에 두텁게 잠겨 있어 이 grill은 발명이 아니라 **이행 + 잠정 수치 확정**이다. 스타듀 위키 미러 대조(날씨 규칙·daily luck ±0.1과 5등급 문턱·계절 1일 재스폰·잡초 확산 예외·"시간 흐르는 축제" 문법)와 코드 전수 감사(훅 지점 12곳·깨질 가정 11건)를 근거로 한다.

## 결정

### 1. 절기 달력 개통 — RUN_DAYS 게이트 폐지 (★최대 파급)
`RunSummary.RUN_DAYS=21` 종료 게이트(`main.gd:8719`) 때문에 **절기 전환(day 29)에 영원히 도달 불가** — Slice 7의 전제가 성립하지 않는다. CONTEXT가 이미 답을 갖고 있다("현재 14/21일 슬라이스는 재미 게이트용이었지 최종 길이가 아니며 풀 절기 달력으로 확장된다"). 조치:
- **런 종료 게이트만 제거**(호출부 2곳 — 취침 `_on_day_advanced`·세이브 재개 `_begin_game`. 초안은 1곳으로 봤으나 T1 구현이 재개 입구를 적발해 함께 닫음 — 한쪽만 닫으면 day 22+ 세이브 재개가 마무리 화면으로 떨어져 달력이 도로 막힌다). `RUN_DAYS` 상수·정산 화면·호감도 곡선 파생(`Affinity.POINTS_PER_HEART`)은 **전부 보존** — 하트 페이싱 불변, `playtest_bot` 21일 루프 불변. 정산 화면은 엔딩(S9 해방) 재사용 자산으로 이연.
- 절기 전환 = **main 명시 전파**(시그널 아님 — day advance 체인이 이미 명시 순서 설계): `GameClock.is_season_first_day(d)` static 신설, `_on_day_advanced`에서 판정해 각 시스템에 순서대로 전파. `forage_spawn.gd:203` 로컬 판정은 이 static으로 교체(이중 발화 차단). `_dos`(절기 내 일차) 중복 구현 2곳(main·berry_bush)도 clock static으로 수렴.

### 2. 작물 절기 — `seasons` 필드 신설·사멸 패스·성야 농사 존치
- `crops.gd` CATALOG에 어종 동형 `seasons: []` 필드 신설(빈 배열=사철). **로스터 배정(잠정):** 혼령초=유화 · 황천포도=망연 · 영혼호박=성야 · 불사과=다절기(필드 무관 생존) · 잔여 작물=피안 중심 배정(빌드 시 전 로스터 표 확정). **성야절 농사 존치** — 스타듀 "겨울 농사 불가"는 비채택(CONTEXT "성야절=영혼 호박이 어울림"이 이미 함의·저승은 겨울도 삶의 절기). 절기당 작물 최소 1종 보장.
- **사멸 = main 별도 패스**(절기 1일 아침, `farm.advance_day` 직전): 비제철·비다절기 작물 일괄 제거. `field.gd` 시그니처 불변(기존 테스트 7종 무영향). **과수(orchard) 불참**(ADR-0045 불가침 유지) · `is_multi_seasonal`(`crops.gd:252`) 첫 프로덕션 소비.
- 심기 자유 유지 + **만물상 매대=제철 씨앗만 진열**(스타듀 동형) + 씨앗 툴팁 절기 표기. `menu_catalog.gd:219` [S7 훅] 작물 in_season 배선(카페 절기 로테이션 완성).

### 3. 저승 날씨 = 무상태 순수 파생 롤 (세이브 0)
`weather.gd` 신설 — `weather_for_day(d)`: day 시드 결정 롤. ⚠️구현 정정(T3, 2026-08-11): `hash() % 100` 직접 롤은 Godot 문자열 해시(djb2 결)의 하위 비트 선형성 때문에 분포가 붕괴(혼불 바람 1년 0회 실측) — `rand_from_seed`(PCG 믹싱) 한 겹으로 결정성 보존+분포 수렴. 저확률 출목의 hash 결정 롤은 이후로도 이 관례를 따른다. **clock 무상태 원칙 보존**·내일 100% 예보가 공짜(`weather_for_day(day+1)`)·세이브 키 0. 모든 세이브 동일 날씨 시퀀스는 수용(cafe want 롤 선례 — 세이브별 분기가 필요해지면 가법 시드 키 1개로 해소 가능, owner 큐).
- **타입·분포(%):** 피안 70평온/25혼우/5혼불 · 유화 70/10/20혼불 · 망연 65/30/5 · 성야 55평온/40잿눈/5혼불(혼우 0 — 스타듀 "겨울 비 없음" 동형).
- **강제 평온:** 절기 1일 + 테마 데이 당일(분포 무시 오버라이드).

### 4. 날씨 효과 배선 (전부 기존 훅)
- **혼우(비):** 아침 자동 급수 — `main.gd:8759` 스프링클러 블록 옆에서 `field.sprinkle` 재사용(**field.gd 수정 0**) + 낚시 입질 +25%.
- **잿눈(눈):** 노지 작물 그날 성장 정지+물 마름(비살상 — 가법 인자) · 방목 금지(`_weather_calm()` 스텁 실효화 — return 1줄) · 카페 손님 가중 +50%.
- **혼불 바람:** 던전 한정 — 잡귀 스폰 ×1.5·드랍 ×1.5·희귀 ×2(S5가 열어둔 함수 인자 배선) · 지상=연출만·카페 무효.
- **어종 날씨:** `fish_catalog.is_available`에 weather 인자(예약 필드 첫 평가) — 혼우 한정 2종 태그(도깨비메기·먹빛장어 잠정).
- ⚠️ **`cafe.spawn_scale` 단일 곱 자리 준수**: 날씨 배수는 `main.gd:14837`(축제×단계 곱 자리)에 함께 곱한다 — 별도 대입 금지(선행 사고 주석 존재).

### 5. 명부의 운 — 파생 롤 ±0.1·5등급·배선 6지점
`daily_luck.gd` — `luck_for_day(d)` = `hash("luck:%d")` → −0.10~+0.10(스타듀 동형). 등급 5구간(문턱 ±0.02/±0.07 — 스타듀 Fortune Teller 동형)·**TV엔 등급만 노출**(수치 숨김). 배선(잠정 6지점 — 플레이어 액션 롤에만, 월드 결정성 침해 금지·작물 성장 제외): ①갱도 사다리 발견 ②지오드 드롭 ③잡귀 드랍 ④벌목 보너스(원목/씨앗) ⑤낚시 인양 롤 ⑥작물 다수확 yield 롤.

### 6. 예보 매개체 = "점괘 거울" (서랍 해소)
명칭 잠정 확정 **점괘 거울**(무녀 옥자 점술 결·기물 아트 1장·라디오보다 시각 정합). 집 북벽 가구 1종 + `facing_tv` 판정(상자 패턴 `main.gd:10047` 복제) + 아침 예보 팝업: **오늘 운 등급 + 내일 날씨(100% 확정) + D-1 절기 사멸 경고 + 다가오는 행사 예고** 한 화면.

### 7. 잡초 확산·파괴 + 절기 재스폰 (ADR-0055 부분 정밀화)
- **밤 재점령 = ADR-0055 그대로**(빈 맨땅만·1~2칸·성역 불변).
- **확산 신설**(owner 2026-07-05 채택 이행): 기존 잡초가 인접 칸으로 번짐 — 잡초당 6%/일(혼우·절기 1일 ×2). **파괴 O**: 목적지의 작물·스프링클러류 제거 후 점유. 면제=상자·건물·울타리(SOLID)·과수(스타듀 동형). 파괴 시 아침 알림. 성역과 비충돌(성역=무에서 스폰 금지 / 확산=방치한 잡초의 예고된 잠식 — 관리 실패의 가시적 결과, 기습 아님).
- **절기 전환 1일 대량 재스폰**: 빈 맨땅 후보에 잡초 위주+debris(업화석·석화 고목) 소량 혼합, 규모 잠정 8~16(레버). ADR-0055 "치운 자리 성역"은 그 자리 한정이라 비충돌.
- **성야절 = 확산 정지·재스폰 없음·지상 잡초 소멸**(스타듀 겨울 + ADR-0055 겨울 정지 정합).
